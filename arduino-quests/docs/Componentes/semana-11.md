# Lista de Componentes utlizados para a montagem de um LED com três estados 

| Componente | Modelo / Valor | Quantidade | Função no Circuito |
| :--- | :--- | :--- | :--- |
| **Arduino Uno** | R3 | 1 | [cite_start]Executar o código de programação e fornecer a tensão necessária para alternar os padrões de pisca do LED[cite: 127]. |
| **LED** | Vermelho (ou cor padrão) | 1 | [cite_start]Sinalizar visualmente as três sequências de teste programadas (lento, rápido e personalizado)[cite: 128, 134]. |
| **Resistor** | $220\ \Omega$ ou $330\ \Omega$ | 1 | [cite_start]Limitar a corrente elétrica para proteger o LED de sobrecarga quando a porta digital for acionada[cite: 85, 106]. |
| **Protoboard** | 400 pontos | 1 | [cite_start]Servir como base física para conectar eletricamente o LED e o resistor de forma rápida e segura[cite: 11, 127]. |
| **Fios (Jumpers)** | Macho-Macho | 2 | [cite_start]Realizar a ligação da porta digital escolhida para o resistor/LED e fechar o circuito retornando ao pino GND[cite: 12]. |
